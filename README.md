# נטופוליס: העיר שאיבדה חיבור

משחק היכרות לתלמידים חדשים שמתעניינים במגמת **תקשוב** (רשתות תקשורת ואבטחת מידע).
התלמיד בוחר דמות (בן/בת, תסרוקת, בגדים ואביזרים), נכנס דרך פורטל לעיר עתידנית, ומגלה שהחיבורים בה נופלים.
הוא עובר 6 אזורים, בכל אחד מנסה לעשות דבר יומיומי, נכשל בגלל תקלת תקשורת, ופותר משחקון שמלמד מושג אמיתי.
בסוף העיר נדלקת, והוא מקבל גלימה, תעודה להורדה וקריאה להצטרף.

## איך מריצים

- **הכי פשוט:** לפתוח את `index.html` בדפדפן (Chrome / Edge / Safari). אין צורך בשרת, בהתקנה או באינטרנט (פרט לפונט Rubik מ-Google Fonts; בלעדיו נעשה שימוש בפונט מערכת).
- **לשיתוף עם תלמידים:** לפרסם ב-GitHub Pages (`Settings → Pages → Deploy from a branch`) ולשלוח את הקישור.
- **מכשירים:** מחשב, טאבלט וטלפון (במצב אופקי). בנייד מחזיקים אצבע על המסך כדי ללכת.

## מבנה המשחק

| שלב | אזור | הדמות מנסה | התקלה | משחקון | מושג |
|---|---|---|---|---|---|
| 0 | שער הכניסה | להיכנס לעולם | - | יצירת דמות + כניסה דרך פורטל | - |
| 1 | כיכר הרשת | לשלוח הודעה | נתקעת | **מסלול החבילה**: כתובת IP וניתוב דרך נתבים | רשתות ונתבים |
| 2 | תחנת הרכבת | לסרוק כרטיס | שגיאת שרת | **כבל הרשת**: 8 חוטים לפי תקן T568B | כבלים ותשתית |
| 3 | מרכז מסחרי | לשלם | נחסם | **מגן הסייבר**: זיהוי פישינג + בניית סיסמה חזקה | אבטחת מידע |
| 4 | בית החולים | לפתוח תיק רפואי | כופרה | **חומת האש**: חסימת חבילות זדוניות בזמן אמת | חומת אש וגיבוי |
| 5 | מעבדת AI | לשאול את ה-AI | אין לו דוגמאות | **אימון ה-AI**: מסווג שלומד מדוגמאות ומצבע מפה | בינה מלאכותית |
| 6 | ליבת העיר | להפעיל את הליבה | לא מגיבה | **הפעלת הליבה**: חיבור כל הבעיות לפתרונות + טעינה | סיכום |

- **ביט**: עוזר ה-AI שמלווה את השחקן, מסביר, נותן רמזים, ומייצג את הנושא "AI במגמה".
- כל אזור מתחיל "כבוי" (אדום, קופצני, כבלים שבורים) ונדלק בצבעים כשהתלמיד מתקן אותו.
- דירוג של 1-3 כוכבים לכל משחקון לפי מספר הטעויות, ובסוף תעודה אישית עם דרגה.
- התקדמות נשמרת אוטומטית (localStorage), ויש כפתור "המשך משחק שמור".
- משך משחק: כ-10 דקות.

## התאמה אישית

| מה | איפה |
|---|---|
| שם בית הספר / המגמה, קישור הרשמה, נתיבי לוגו וסרטונים | `js/config.js` |
| כל הטקסטים והדיאלוגים (בעברית, עם התאמה למגדר) | `js/content.js` |
| תמונות רקע, סרטונים ולוגו (אופציונלי) | `assets/`: **ראו `assets/PROMPTS.md` לפרומפטים מדויקים** |

> **חשוב:** ההסברים המקצועיים ב-`js/content.js` (כרטיסי "מושג חדש נלמד", וסעיף "במגמה: ...") נכתבו באופן כללי. כדאי שמורה מהמגמה יעבור עליהם ויתאים לתוכנית הלימודים האמיתית.

## מבנה הקוד

```
index.html        מבנה הדף
css/style.css     עיצוב הממשק (HUD, דיאלוגים, יוצר הדמות, תעודה)
js/config.js      הגדרות לעריכה
js/content.js     טקסטים
js/util.js        כלי עזר, טקסט בעברית על קנבס, חלקיקים
js/audio.js       מוזיקה ואפקטים (הכול מסונתז בקוד, אין קבצי שמע)
js/character.js   הדמות המותאמת אישית + ביט
js/world.js       העולם: אזורים, פרלקסה, אנימציות, מצב "כבוי/דלוק"
js/minigames.js   6 המשחקונים
js/game.js        לולאת המשחק, סצנות, קלט, דיאלוגים, שמירה, סיום ותעודה
assets/           נכסים אופציונליים + PROMPTS.md
```

הכול ב-JavaScript רגיל (ללא ספריות וללא build), ורץ ישירות מהקובץ.

## פרטיות

המשחק רץ כולו בדפדפן. אין שרת, אין איסוף נתונים. השם שהתלמיד מקליד נשמר רק במכשיר שלו, והתעודה נוצרת מקומית. בתוך המשחק מוצג במפורש לא להקליד סיסמה אמיתית.
