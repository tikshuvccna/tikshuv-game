# נטופוליס 3D

גרסת תלת-ממד של המשחק: עיר עגולה שאפשר להסתובב בה לכל הכיוונים, עם ליבה במרכז וחמישה מבנים סביבה. השחקן בוחר לאיזו כניסה להיכנס, ובכל כניסה מחכה משימה קצרה (אותם משחקונים כמו בגרסה 2).

**כתובת:** `/3d/` (הגרסאות האחרות: `/` ו-`/v2/`).

## שליטה
- **מחשב:** הליכה ב-`W A S D` או בחיצים · סיבוב מצלמה: גרירת העכבר (או `Q` / `E`) · זום: גלגלת · `M` להשתקה.
- **טלפון / טאבלט:** ג'ויסטיק בפינה · סיבוב מצלמה: גרירה על המסך · זום: צביטה.
- כדי להיכנס למבנה עומדים על העיגול הזוהר שבכניסה. אפשר גם ללחוץ על האייקונים למעלה כדי לקפוץ לאזור.

## בנייה מחדש (למי שרוצה לשנות את הקוד)
המשחק כתוב ב-Three.js ומאוגד לקובץ אחד, `game3d.js` (הוא כבר מצורף בריפו, כך שאין צורך לבנות כדי להריץ).

```
cd 3d
npm install
npm run build      # יוצר את game3d.js מתוך src/
```

| קובץ | תפקיד |
|---|---|
| `src/world3d.js` | העיר: מבנים, שמיים, תאורה, חלקיקים, מצב "כבוי/דלוק" |
| `src/avatar.js` | הדמות התלת-ממדית המותאמת אישית |
| `src/main.js` | לולאת המשחק, מצלמה, קלט, דיאלוגים, סיום ותעודה |
| `js/` | טקסטים, קול, ומשחקוני ה-2D שמוצגים מעל העולם (משותפים לגרסה 2) |

## ביצועים
- במחשבים יש אפקט זוהר (bloom). בטלפונים הוא כבוי אוטומטית. אפשר לכבות גם ידנית עם `?nobloom` בסוף הכתובת.
- דורש דפדפן עם WebGL2 (Chrome, Edge, Safari, Firefox עדכניים).
